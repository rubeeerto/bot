# 🎵 Добавлены новые методы скачивания музыки

## ✅ Новые провайдеры добавлены:

### 1. **BandcampProvider**
- **Источник**: Bandcamp.com
- **Особенности**: Независимые артисты, высокое качество
- **Метод**: Поиск через HTML + скачивание через yt-dlp

### 2. **ArchiveOrgProvider** 
- **Источник**: Internet Archive (Archive.org)
- **Особенности**: Исторические записи, классическая музыка
- **Метод**: API поиск + прямые MP3 ссылки

### 3. **FreeMusicArchiveProvider**
- **Источник**: Free Music Archive
- **Особенности**: Бесплатная музыка с лицензиями Creative Commons
- **Метод**: HTML парсинг + прямые MP3 ссылки

### 4. **JamendoProvider**
- **Источник**: Jamendo.com
- **Особенности**: Бесплатная музыка, API доступ
- **Метод**: Официальный API + прямые ссылки на аудио

### 5. **MixcloudProvider**
- **Источник**: Mixcloud.com
- **Особенности**: Миксы, подкасты, длинные записи
- **Метод**: HTML парсинг + yt-dlp скачивание

## 🔧 Технические особенности:

### Каждый провайдер включает:
- ✅ **Async/await поддержка** для неблокирующих запросов
- ✅ **Timeout защита** (15 секунд на запрос)
- ✅ **Error handling** с детальным логированием
- ✅ **Clean filename** для безопасных имен файлов
- ✅ **MP3 конвертация** через FFmpeg

### Различные методы скачивания:
- **Прямые MP3 ссылки** (Archive.org, FMA, Jamendo)
- **yt-dlp скачивание** (Bandcamp, Mixcloud)
- **API + парсинг** (все провайдеры)
