# 🔧 Исправление FFmpeg проблем с SoundCloud

## ❌ Проблема:
```
ERROR: Postprocessing: WARNING: unable to obtain file audio codec with ffprobe
yt_dlp.utils.PostProcessingError: WARNING: unable to obtain file audio codec with ffprobe
```

## ✅ Решение:

### 1. **Улучшенные настройки FFmpeg**
Добавлены специальные параметры для обработки проблемных аудио файлов:

```python
'postprocessor_args': {
    'FFmpegExtractAudio': [
        '-acodec', 'mp3',
        '-ab', '192k',
        '-ar', '44100',
        '-ac', '2',
        '-avoid_negative_ts', 'make_zero',
        '-fflags', '+genpts'
    ]
},
'ignoreerrors': True,  # Игнорируем ошибки постобработки
```

### 2. **Альтернативная обработка файлов**
- **Поиск в разных форматах**: mp3, webm, m4a, ogg, wav
- **Ручная конвертация**: Если FFmpeg не справляется, используем subprocess
- **Fallback на исходный файл**: Если конвертация не удалась, возвращаем оригинал

### 3. **Улучшенная обработка ошибок**
- **Детальное логирование** каждого шага
- **Graceful fallback** между форматами
- **Timeout защита** для конвертации

## 🔧 Технические детали:

### Параметры FFmpeg:
- `-acodec mp3`: Принудительное использование MP3 кодек
- `-ab 192k`: Битрейт 192 kbps
- `-ar 44100`: Частота дискретизации 44.1 kHz
- `-ac 2`: Стерео звук
- `-avoid_negative_ts make_zero`: Исправление временных меток
- `-fflags +genpts`: Генерация временных меток

### Логика обработки:
1. **Скачивание** через yt-dlp с улучшенными настройками
2. **Поиск файла** в разных форматах
3. **Конвертация** через subprocess если нужно
4. **Fallback** на исходный файл
